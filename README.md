##  Key Features

* **✨ AI Performance Advisor:** Automatically analyzes cohort academic metrics and generates instant smart insights.
* **📊 Comprehensive Dashboard:** Real-time tracking of total enrolled students, course distribution, and overall average GPA.
* **🏅 Dynamic Academic Standing Badges:** Automatic categorization of student performance (*First Class Honors, Second Class, General*).
* **🔍 Advanced Filtering & Sorting:** Instant search by student name/email, course filtering, and multi-criteria sorting (GPA, Name).
* **📥 Professional CSV Export:** One-click data export generating cleanly formatted reports for administrative use.
* **🔒 Strict Form Validation & State Persistence:** Robust client-side error handling, duplicate email checks, and persistent data storage using browser `LocalStorage`.
* **🌙 Dark / Light Mode Support:** Fully responsive modern UI built with custom CSS variables for seamless theme switching.

---

##  Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox & CSS Grid), Modern JavaScript (ES6+)
* **Storage:** Browser LocalStorage API
* **Design Philosophy:** Clean, Minimalist Enterprise Dashboard UI/UX
